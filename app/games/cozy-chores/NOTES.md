farin-app, 2026-10-23; v0.3 on 2026-10-29. The engine and all five anchor projects: Moving-In Day (A1), Happy Birthday, Ada (A1/A2/B1), The Wedding Bouquet (B1), Big Laundry Day (B2), Street Party Saturday (C1), EN + ES. ## Art drops in by filename
1. Render each entry of `art/manifest.json` at its `size` and save it as `art/<id>.webp` in both apps (plates 864×1080 ≤ 150 KB; cut-outs with alpha ≤ 30 KB; portraits 600 px tall).
2. Run `node Claude/specs/games-expansion-2026-10-22/cozy-chores-tools/build-manifest.mjs`. Any entry whose file exists becomes `ready:true`, and the engine draws it instead of the placeholder.
3. Run `build-demo.mjs`: the demo inlines every ready file.

Two layout rules for the painters (also in the plate `hits` lists of the manifest):
- On phones the order note sits over the top-right corner of the panel (x > 80 %, y < 12 %). Nothing interactive goes there.
- `co-cream-spiral` is drawn white: the engine tints it with the chosen colour through a CSS mask, so one file serves all four colours.

## Requests for the Theatre owner (do not block the slice)
1. **An exit guard.** The GDD wants × to ask "Leave? Your place is saved." first. Today `Theatre.exit()` calls `onExit` straight away and force-closes after 700 ms, so a game cannot ask. Cozy Chores works around it: while it runs it catches clicks on `.th-x` and Escape in the capture phase, shows its own dialog, and calls `Theatre.exit()` (or the host's `onLeave`) on Leave. Proposed API: `Theatre.open({..., exitGuard: () => Promise<boolean>})`. × and Escape would await it, and `false` would mean stay. With that in place the capture listeners in `engine.js` (`guardExit`) can go.
2. **JSON in the service-worker rule.** `GAMES_RE` caches `games/**/*.js|css`. Cozy Chores also lazy-loads `games/cozy-chores/projects/*.json`, `content/*.json` and `art/manifest.json`, and these need the same stale-while-revalidate rule to work offline. The art WebPs fall under `IMG_RE` already.
3. **FYI, poster rule.** Until `posters/chores.webp` exists, the Theatre skips the poster, so learners will not see the project strip or Continue. A saved round then resumes directly at its station start, which is what GDD 11 asks for. The harness and the demo pass `forcePoster` because they are previews.

## App wiring for the app-file slot (later; about 2 KB in each app file)
- Load lazily, like `theatreLoad()`: `games/cozy-chores/chores.css` + `engine.js`, then `CozyChores.load({appRoot:''})`.
- In the Theatre `onPlay` for kind `chores`, call `CozyChores.start({root:Theatre.stageEl(), data, lang:TTS_LANG.slice(0,2), ui:LANG, band:<anchor band for the learner's level>, name, host, resume:!!state.viewParams.round, onDone, onLeave})` with this host:
  - `speak(text, {lang, rate, interrupt})`: return a Promise around `ttsSpeak(text, rate, {end, error})` (natural voices), and call `stopAllSpeech()` first when `interrupt` is set.
  - `stopSpeech: stopAllSpeech`, `sfx: name => { sfx(name); }` (return `true` only for names the app plays itself), `muted: () => sfxMuted`, `reduced: reducedMotion`.
  - `loadRound / saveRound`: `state.viewParams.round` + `save()`.
  - `loadHouse / saveHouse`: `state.progress.house` + `save()`. It needs a save-merge guard like `progress.chores` (L19117).
  - `keep(s)`: `gameKeep('chores', {plan:s.text})`. gameKeep's chores branch reads `round.plan`; its `note` should become `s.note`.
- `onDone(result)`: `markGameComplete` + `scoreGameCompletion` (never shown), then `backToRoadmap()`, and `maybeCelebrate` plays.
- `onLeave`: `theatreExit()`.
- Band per level: the learner's own level. Every project plays at A1, A2, B1, B2 and C1 (v0.4), so the shelf can pass `band:level` for any project.

## v0.4.1 (2026-10-31): a press is never silently refused
- **The bug:** drag-to refused every press while a line played (`G.busyLine`; place had `busyDrop`, pour `busyPour` / `busyCheck`, the dial `busy`), with no feedback. Measured at real speed: 5-6 s after one wrong drop, 11 s when the voice never reports its end.
